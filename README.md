# Modex Design - 3D Printing & Prototyping

Full-stack 3D printing, CAD modeling, and precision prototyping platform.

## Features
- Interactive 3D CAD Reel with Three.js
- Dual-language support (Ukrainian / English)
- Responsive layout with Tailwind CSS & Alpine.js
- Scroll animations via AOS
- Fast client intake workflow
- Ready for serverless deployment on Vercel

## Tech Stack
- Laravel 12 / PHP 8.3+
- Livewire 4 & Flux UI
- Tailwind CSS v4 & Vite
- Alpine.js & AOS
- Three.js
